# Хованки — Славік, Даша й Катя

Піксельна гра для одного гравця з видом зверху-збоку. Обери одного з трьох героїв і зіграй у будинку, на майданчику або в майстерні. Двома іншими героями керує гра.

## Як грати

- **Шукати.** Після короткого відліку знайди обох друзів за 45 секунд. Блиск біля предмета підказує, звідки долинув шурхіт.
- **Ховатися.** За 12 секунд займи вільну схованку й протримайся 38 секунд, поки друг оглядає карту.
- **Керування.** Стрілки або WASD для руху, E або пробіл для дії, Esc для паузи. Також можна клацнути чи торкнутися підлоги або предмета.

Для локальної гри відкрий `index.html` у браузері. Усі ресурси гри є в цій папці.

## Публікація на GitHub Pages

1. Створи або відкрий репозиторій GitHub. Для нового репозиторію можна використати назву `hovanky`.
2. Завантаж розпаковані файли в корінь гілки `main`. Файли `index.html`, `.nojekyll` і папка `assets` мають бути на одному рівні.
3. У **Settings → Pages → Build and deployment** вибери **Deploy from a branch**, потім `main` і `/(root)`. Натисни **Save**.
4. Коли розгортання завершиться, відкрий **Settings → Pages → Visit site**.

[Офіційна інструкція GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
